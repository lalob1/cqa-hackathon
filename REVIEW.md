# Democrats · Проверка CQA

## Запуск без скачивания модели

Понадобятся Python 3.10+ и браузер. Выполните из корня репозитория в PowerShell.

```powershell
$env:CQA_DB = "data/reviewer.sqlite3"
python workflow.py import --dataset examples/reviewer-dialogues.json --input examples/reviewer-runs.json
if ($LASTEXITCODE -ne 0) { throw "Не удалось загрузить демонстрационные оценки." }
python app.py
```

Откройте [локальное приложение](http://127.0.0.1:8765/) и нажмите стрелку под логотипом. В левой панели находятся **Диалоги**, **Оценка** и **Чек-лист**. На узком экране панель открывается кнопкой меню.

В демо четыре синтетических чата на RU, KZ и EN с сохранёнными оценками, полученными от Qwen3-4B на V4. Повторный импорт сохраняет уже внесённые апелляции. Для чистой репетиции укажите новый файл `CQA_DB`. Для новой оценки подключите модель по [инструкции запуска](README.md#запуск-с-llamacpp).

## Пять минут на проверку

| Время | Действие |
| --- | --- |
| 0:00–1:00 | Найдите `rehearsal-01` и откройте карточку. Покажите переписку, исходный язык и доступные фильтры. |
| 1:00–3:00 | В оценке раскройте консультацию и нажмите номер реплики. В критерии идентификации покажите N/A и пересчитанный вес. В **О запуске** доступны итоги секций и версия чек-листа. |
| 3:00–4:00 | В консультации подайте апелляцию, выберите 5 баллов по шкале и сохраните решение с пояснением. В учебном сценарии итог меняется с 93.75 до 81.25. Исходная оценка остаётся в карточке. |
| 4:00–5:00 | Измените правило критерия, сохраните чек-лист и запустите **Новую оценку** с подключённой моделью. Покажите, где результат сохраняет новую версию чек-листа. Запуск может завершиться после показа. |

Для грубой ошибки найдите `rehearsal-10` через фильтр **Грубые ошибки ИИ**. Флаг отображается отдельно от итогового балла. Результаты с неподтверждёнными критериями доступны в фильтре **Требуется проверка**. У такого запуска нет полного балла до завершения проверки моделью.

## Контрольный прогон

1. Сохраните JSON организатора как `data/control.json`. Если выдан `group_id`, получите данные командой ниже. Храните подписанную ссылку в локальном `data/control-url.txt`.
2. Проверьте, что получены именно 10 чатов с исходными ID. Запустите оценку с исходным чек-листом и зафиксированным SHA-256 весов.
3. Проверьте итоговый файл. Экспорт сохраняет по строке на каждый ID. Ошибки имеют `status: "error"` и причину. Если осталось время, повторите только ошибки и незавершённые случаи.
4. Добавьте `results/prod/results.json` в Git. По приложению к гайду оба файла должны быть доступны по открытой ссылке, переданной организатору до стоп-кода. Уточните канал и точное время у организатора.

Если выдана ссылка и значение группы, выполните:

```powershell
if (-not $env:CQA_CONTROL_GROUP) { throw "Укажите выданный организатором group_id." }
python batch.py fetch --url-file data/control-url.txt --group $env:CQA_CONTROL_GROUP --output data/control.json
if ($LASTEXITCODE -ne 0) { throw "Не удалось получить контрольный набор." }
```

Затем запустите следующий блок с настроенной моделью и переменной `CQA_MODEL_REVISION`, содержащей SHA-256 её файла.

```powershell
if (-not $env:CQA_MODEL_REVISION) { throw "Укажите SHA-256 весов в CQA_MODEL_REVISION." }

python -c "from engine import extract_records, read_json; rows = extract_records(read_json('data/control.json')); assert len(rows) == 10 and all(r['channel'] == 'agent chat' for r in rows), 'Expected 10 control chats'"
if ($LASTEXITCODE -ne 0) { throw "Проверьте контрольный набор." }

$cqaResume = @()
if (Test-Path -LiteralPath runs/control.json -PathType Leaf) { $cqaResume = @('--resume') }
python batch.py score data/control.json --expect-count 10 --model-revision $env:CQA_MODEL_REVISION --output runs/control.json @cqaResume
if ($LASTEXITCODE -notin 0, 1) { throw "Проверьте параметры запуска и контрольный набор." }

python batch.py export data/control.json runs/control.json --group prod --team-name Democrats
if ($LASTEXITCODE -eq 1) { Write-Warning "Файл создан с ошибками обработки. Проверьте строки status=error." }
elseif ($LASTEXITCODE -ne 0) { throw "Не удалось создать файл для сдачи." }
```

Для повторного запуска оставьте модель, входной набор и чек-лист прежними. Если времени мало, после остановки прогона можно выполнить отдельно команду `export` для последней сохранённой контрольной точки. Экспорт выставит статус ошибки для отсутствующих или неполных оценок. До отправки проверьте наличие обеих папок в Git и соответствие последнего коммита зафиксированной версии.
