# DEV: проверка небольшой выборки

Обновлено 8 ноября 2026 года.

Итоговая конфигурация V11. Предыдущий полный диагностический V9 сохранён в [DEV_REVIEW_V9.md](DEV_REVIEW_V9.md); его расхождения и отклонённые случаи стали основанием дополнительных исправлений.

12 DEV-чатов: по четыре RU/KZ/EN, 96 предварительных решений ассистента, записанных до просмотра V4. Это калибровочная выборка, не независимый тест и не официальный Ground Truth. Исходные транскрипты и подробная локальная разметка в Git не добавлены.

Новая версия: принято 10/12 результатов; ошибок обработки: 2.
Исторический V4: 12/12 результатов, MAE 8.8558 по всей выборке. При разном покрытии сравнивать нужно приведённые ниже общие успешные пары.
Время на этой машине для 10 принятых оценок: медиана 232.5 с, диапазон 192.7–410.2 с (включая повторные запросы). Время неуспешных случаев в эту медиану не входит.
Грубые нарушения среди принятых результатов: TP=1, FN=0, FP=0, TN=9. Покрытие положительных случаев предварительного разбора: 1 из 2; отклонённые случаи не считаются найденными нарушениями.
На общих 10 успешных парах MAE итога: V4 8.371 → новая версия 4.954. Деноминатор и ошибки указаны отдельно; пропуски не приравниваются к совпадениям.
Точные значения на тех же парах: 55/80 → 70/80. Эта метрика не проверяет качество объяснений.

Обнаруженные повторяющиеся проблемы: приписывание бота/клиента оператору, N/A и пропущенное действие, прощание без итога/помощи, неподтверждённая идентификация перед раскрытием статуса счёта, причина, не соответствующая процитированной реплике.

Изменения выбраны по этому разбору: ограниченный режим рассуждения Qwen, проверки доказательств и повторный запрос только по невалидным критериям с сохранением остальных решений. Проверки не вставляют ответы из разметки и не содержат исключений по ID диалогов.

Это ретроспективное сравнение с историческим V4, у которого нет полного снимка настроек. Менялись несколько компонентов; это не эксперимент с одним изменяемым фактором. Замечания аудита к объяснениям и доказательствам: 34. Расхождения N/A в принятых значениях относительно предварительного разбора: 3. Это разные показатели. Пройдено тестов unittest: 92. Проверен синтаксис JavaScript. Они проверяют расчёт, сохранение, импорт/экспорт, защиту ревизий и контракт модели, а не её точность.

В браузере проверены новый диалог → реальная оценка → доказательство → апелляция → решение → пересчёт, восстановление серверной истории без localStorage, изменение чек-листа и сохранение старой версии. Дополнительные проверенные сценарии перечислены в WORKFLOW_UPDATE_RU.md и локальном отчёте.

Ограничения: нужна человеческая сверка спорной разметки; точность относительно официальных ответов не измерена. Корректность консультаций разбиралась по транскрипту; утверждённая база операционных правил компании не предоставлена. Live inference проверен через llama.cpp; Ollama в этом прогоне не использовался. Новый контрольный набор из 10 чатов не предоставлен и не подменяется DEV.
